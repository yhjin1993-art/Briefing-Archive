오늘의 용어

glossary.md 미수록 용어만, 예시 1줄 포함
환매청구권 Put-back Option (IPO Investor Put)
공모주 일반청약자가 상장 후 정해진 기간에 주가가 공모가의 90% 아래로 떨어지면 주관사에 공모가의 90%로 되팔 수 있는 권리. 기술특례/성장성 특례 상장 등에서 주관사가 부담한다.
예: 바로팜 공모가 16,400원 → 행사가 14,760원, 34,685주 x 14,760원 = 약 5.1억
신주인수권증서 Subscription Rights Certificate
주주배정 유상증자에서 기존 주주가 받은 "신주를 발행가에 살 권리"를 증서로 만든 것. 상장되어 사고팔 수 있어, 청약하지 않는 주주는 이를 팔아 희석 손실을 일부 메운다.
예: 삼성바이오 증서 보유 주주 청약률 98.7%, 우리사주 89.3%
이론권리락가 Theoretical Ex-Rights Price (TERP)
유상증자 후 주가의 이론값. (기존 시가총액 + 증자 대금) ÷ (기존 주식수 + 신주). 발행가 할인이 클수록 TERP가 낮아지고, 그 차이가 신주인수권의 가치가 된다.
예: 1,000만주 x 10,000원 + 신주 200만주 x 8,000원 → 1,160억 ÷ 1,200만주 = 9,667원
급여적정성 재평가 Reimbursement Adequacy Re-evaluation
이미 건강보험이 적용되는 약이 임상적 유용성, 비용효과성 기준을 계속 충족하는지 다시 평가해 급여 축소나 삭제를 결정하는 절차. 상한가를 다시 매기는 기등재 재평가와는 별개.
예: 은행엽엑스, 도베실산칼슘, 실리마린 3개 성분, 최근 3년 평균 청구 약 1,400억
매몰비용 Sunk Cost
이미 써서 되돌릴 수 없는 비용. 투자를 계속할지 판단할 때는 넣지 않고, 앞으로 들어갈 돈과 앞으로 벌 돈만 비교한다. "이미 쓴 게 아까워서" 계속하는 것이 매몰비용 오류.
예: 부지, 설계에 100억을 썼어도 추가 900억 투입의 NPV가 -50억이면 철회가 맞다(가정)

회사가 돈을 받고 새 주식을 발행하는 것. 오늘은 삼성바이오가 기존 주주에게 먼저 배정하고 남은 물량을 일반에 판 방식으로 2조6,650억을 모았다.
▸ 상장사 대형 투자, M&A 재원 조달

실권주 Unsubscribed Shares
배정받은 주주가 청약하지 않아 남은 신주. 오늘 삼성바이오는 구주주 청약률 96.8%로 남은 약 3%를 일반공모로 팔았다.

▸ 증자 할인율, 희석 효과 설명

이미 써서 되돌릴 수 없는 비용. 팜젠의 철회 판단처럼 이후 투자의 경제성만 보고 결정한다.
▸ 증설 중간 점검, 프로젝트 중단 판단
예: 기투입 100억은 빼고 잔여 900억 투자 NPV로 판단(가정)

B. 심화

이론권리락가와 증자 희석Theoretical Ex-Rights Price (TERP)
"확정 발행가액 117만4000원 ... 보통주 227만주 발행, 총 2조6650억원 조달" - 뉴스토마토 2026-11-11 (오늘 딜의 발행 조건)
약 15분
① 정의

주주배정 유상증자는 시가보다 싼 발행가로 신주를 찍는다. 증자 뒤 회사 가치는 "기존 시가총액 + 들어온 돈"이 되고 주식수는 늘어나므로, 이론 주가(TERP)는 기존 주가보다 낮아진다. 청약한 주주는 손해가 없고, 청약하지 않은 주주만 희석된다. 그 차이를 메워주는 것이 신주인수권(증서)의 가치다.

계산식
TERP = (N x P + n x S) ÷ (N + n) / 권리가치(신주 1주당) = TERP - S
오늘 수치로
삼성바이오: n x S = 227만주 x 117만4,000원 = 2조6,650억(일치). 기존 주식수 N과 직전 주가 P는 이번 수집 자료에 없어 TERP 산출은 생략.
③ 많이 쓰는 곳, 당사 적용
  • 볼트온, 대형 설비 재원을 차입과 비교할 때: 증자는 이자 없음 + 희석, 차입은 희석 없음 + 이자/약정
  • 맥쿼리 Exit 전 증자 시 지분율과 주당 가치 변화를 이사회 자료로 제시
  • 고객사(상장 제약)가 증자를 발표하면 할인율과 대주주 참여율로 재무 여력을 판단
①-1 계산 예시: 주주배정 증자 160억, 발행가 20% 할인
수치는 전부 가정이며 설명용으로 단순화한 모델. 실제 평가에서는 항목별 가정을 실사 자료로 대체.
단계입력값(가정)계산결과설명

② 발행 조건신주 200만주(20%), 발행가 8,000원200만 x 8,000조달 160억시가 대비 20% 할인
③ 증자 후 가치시총 + 조달액1,000억 + 160억1,160억돈이 들어온 만큼만 가치 증가
④ 증자 후 주식수기존 + 신주1,000만 + 200만1,200만주
⑤ 권리가치TERP - 발행가9,667 - 8,000신주 1주당 1,667원기존 1주당 = 1,667 x 0.2 = 333원

  • 증설/볼트온 필요 자금과 발행가(할인율)를 n x S 자리에
  • 대주주(맥쿼리) 참여율: 미참여 시 지분율 = 기존 보유 ÷ (N + n)
② 개념 맵: 자본 조달 방식(Equity / 준Equity)

④ 개념 확인 (기초 → 응용 → 당사 적용), 풀어본 뒤 정답 확인
Q1. 기존 1,000만주, 주가 10,000원인 회사가 신주 250만주를 7,600원에 주주배정 발행한다. TERP는?
정답/해설 보기
(1,000억 + 250만 x 7,600 = 190억) ÷ 1,250만주 = 1,190억 ÷ 1,250만 = 9,520원. 권리가치는 신주 1주당 9,520 - 7,600 = 1,920원.
Q2. 같은 160억을 발행가 9,000원으로 조달하면 TERP는 예시(8,000원)보다 높을까 낮을까? 숫자로.
정답/해설 보기
신주 = 160억 ÷ 9,000 = 약 177.8만주. TERP = 1,160억 ÷ 1,177.8만 = 약 9,849원(계산치)으로 더 높다. 할인이 작을수록 신주가 덜 찍혀 TERP 하락폭이 작다. 단 할인이 작으면 청약 흥행(실권) 위험이 커진다.
Q3. 당사 가정: 1,000만주, 주당 5만원(지분가치 5,000억). 동결건조 증설 500억을 주당 4만원에 주주배정. 대주주(90% 보유)가 미참여하면 TERP와 대주주 지분율은?
정답/해설 보기
신주 = 500억 ÷ 4만 = 125만주. TERP = 5,500억 ÷ 1,125만 = 약 48,889원. 대주주 미참여 시 지분율 = 900만 ÷ 1,125만 = 80%(90% → 80%). 신주는 나머지 주주나 실권주 인수자에게 간다(가정).
⑤ 실무 적용 (당사 업무 상황에서 이 개념을 쓰는 법), 모범답안 + 체크포인트
P1. [투자 심의] Exit 준비 중인 당사가 동결건조 라인 증설 500억을 (A) 인수금융 추가 차입, (B) 대주주 주주배정 증자 중 어느 쪽으로 조달할지 검토한다(가정). 판단 기준은?
정답/해설 보기
모범답안: 매각 시 지분가치 = EV - 순차입금이므로 (A)는 Exit 회수액에서 500억이 빠지고 이자 부담이 EBITDA 대비 레버리지 약정을 압박한다. (B)는 맥쿼리가 현금을 더 넣는 대신 회수 시 그대로 돌아온다. 증설의 램프업이 Exit 전에 끝나 EBITDA가 오르면 어느 쪽이든 가치 상승. 체크포인트: ① 기존 대주단 약정(추가 차입 한도, 순레버리지) ② 램프업 완료 시점 vs Exit 일정 ③ 대주주 펀드의 추가 출자 여력(만기, 잔여 약정).
P2. [M&A] 볼트온 대상(비상장 주사제 CDMO) 인수 대금 300억 중 100억을 SI의 제3자배정 증자로 받으려 한다(가정). 가격을 어떻게 정하나?
정답/해설 보기
모범답안: 비상장이라 TERP 대신 프리머니 가치로 협상. 당사 프리머니 5,000억이면 100억 투자 시 SI 지분 = 100 ÷ 5,100 = 약 2.0%. 할인 없이 프리머니를 지키는 것이 기존 주주(맥쿼리) 희석 최소화. 체크포인트: ① 프리머니의 근거(최근 딜 멀티플) ② SI에 줄 권리(이사, 우선매수권)가 Exit 매각성에 주는 영향 ③ 동반매도/우선매수 조항.
P3. [고객사 협상] 상장 고객사가 시가 대비 25% 할인 주주배정 증자를 발표했다(가정). 수탁 계약에서 무엇을 확인하나?
정답/해설 보기
모범답안: 큰 할인은 자금 조달이 급하다는 신호일 수 있다. 증자 자금 용도(신규 품목 출시 vs 차입 상환)와 대주주 참여율을 보고 미수금, 선급금 조건을 점검. 체크포인트: ① 대주주 청약 참여 여부 ② 매출채권 회수 기간, 선급 조건 ③ 증자 실패(대규모 실권) 시 발주 축소 대비 최소 물량 조항.

| 용어 | 풀이 | 당사 관점 |
|---|---|---|
| 환매청구권(Put-back Option (IPO Investor Put)) | 공모주 일반청약자가 상장 후 정해진 기간에 주가가 공모가의 90% 아래로 떨어지면 주관사에 공모가의 90%로 되팔 수 있는 권리. 기술특례/성장성 특례 상장 등에서 주관사가 부담한다. | 당사 IPO 경로에서 이 의무가 붙으면 주관사가 공모가를 보수적으로 잡으려 한다. 맥쿼리 회수가격 하방 요인 |
| 신주인수권증서(Subscription Rights Certificate) | 주주배정 유상증자에서 기존 주주가 받은 "신주를 발행가에 살 권리"를 증서로 만든 것. 상장되어 사고팔 수 있어, 청약하지 않는 주주는 이를 팔아 희석 손실을 일부 메운다. | 당사가 상장 후 주주배정 증자를 하면 대주주 미참여분이 증서 매각, 실권주로 이어진다. 참여율이 흥행 지표 |
| 이론권리락가(Theoretical Ex-Rights Price (TERP)) | 유상증자 후 주가의 이론값. (기존 시가총액 + 증자 대금) ÷ (기존 주식수 + 신주). 발행가 할인이 클수록 TERP가 낮아지고, 그 차이가 신주인수권의 가치가 된다. | 당사 증자, CB 발행 시 기존 주주(맥쿼리) 희석을 숫자로 보여주는 기본 산식 |
| 급여적정성 재평가(Reimbursement Adequacy Re-evaluation) | 이미 건강보험이 적용되는 약이 임상적 유용성, 비용효과성 기준을 계속 충족하는지 다시 평가해 급여 축소나 삭제를 결정하는 절차. 상한가를 다시 매기는 기등재 재평가와는 별개. | Pharma사업부/고객사 품목 중 대상 성분이 있으면 물량 자체가 사라질 수 있음. 약가인하보다 충격이 큼 |
| 매몰비용(Sunk Cost) | 이미 써서 되돌릴 수 없는 비용. 투자를 계속할지 판단할 때는 넣지 않고, 앞으로 들어갈 돈과 앞으로 벌 돈만 비교한다. "이미 쓴 게 아까워서" 계속하는 것이 매몰비용 오류. | 증설 심의 중간 점검(Go/No-go)에서 이미 쓴 설계비, 부지비는 빼고 잔여 투자 NPV로 판단 |
※ 요약/링크만 제공, 원문 복사 없음. 계산치=기사 수치로 작성자가 산출, 추정/보도 기준=미확인. 더벨/인베스트조선/마켓인사이트/링크드인은 사용자 수동 입력분만 반영. 별지(주간 글로벌 트렌드)는 월요일에만 포함.
